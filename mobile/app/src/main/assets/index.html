ดูว่าบอททำอะไรอยู่ จดไอเดีย และตอบคำถาม จากที่ไหนก็ได้ ผ่าน GitHub repo ที่ใช้ sync

  1. ที่ github.com → Settings → Developer settings → Fine-grained tokens → Generate
  2. Repository access: เลือกเฉพาะ repo ข้อมูล sync
  3. Permissions → Contents: Read and write แล้วกด Generate และ copy token

token เก็บไว้ในเครื่องนี้เท่านั้น ส่งไปที่ api.github.com อย่างเดียว

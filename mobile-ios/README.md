# Idea Autopilot — iOS shell

A WKWebView around the same page the Android app uses (`../mobile/app/src/main/assets/index.html`).
Needs a Mac with Xcode (free). See `../docs/IOS.md` for the options, costs (App Store = paid Apple account) and the
free home-screen web-app alternative that needs no Mac.

```sh
brew install xcodegen
xcodegen            # → IdeaAutopilot.xcodeproj (git-ignored)
open IdeaAutopilot.xcodeproj
```

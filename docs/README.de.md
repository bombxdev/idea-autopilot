> Notieren Sie eine Idee in einer Zeile; der KI-Agent Ihrer Wahl recherchiert, bewertet oder baut eine erste Version, während Sie weg sind – mit dem Kontingent, das sonst verfallen würde, und ohne je den Teil anzutasten, den Sie zum Arbeiten brauchen.

## Hauptfunktionen

- **Eine Idee, eine Zeile**: Die KI recherchiert, bewertet und baut Prototypen.
- **Jede KI**: Claude Code, Codex CLI, Gemini CLI, OpenCode, Mistral Vibe oder ein eigener Befehl; mehrere Konten.
- **Nutzt übriges Kontingent**: Ihr Arbeitsanteil wird zuerst reserviert, Arbeitszeiten (Kalender) werden gemieden, nur der Rest wird verwendet.
- **Modell und Aufwand automatisch nach Schwierigkeit**: feste Regeln, keine Tokens fürs Entscheiden.
- **Daten bleiben auf Ihrem PC**: keine Telemetrie, kein Server, pro Idee ein Git-Repository.
- **Skill-Bibliothek**: mehrere „Rezepte“ derselben Art werden abwechselnd getestet und ausgewertet; der kostenlose Skill-Shop prüft vor der Installation die Sicherheit.
- **Smartphone**: Benachrichtigungen und Ideen über Ihren eigenen Telegram-Bot.
- **Oberfläche in 16 Sprachen** (weitere übersetzt Ihre eigene KI).

## Installation (vom Einfachsten an)

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

Benötigt Windows 10/11, Git und mindestens einen angemeldeten KI-Agenten. Windows SmartScreen kann warnen (noch nicht signiert): Weitere Informationen → Trotzdem ausführen.

[Releases](https://github.com/bombxdev/idea-autopilot/releases) — Setup.exe / portable zip

## Sicherheit

Der Bot arbeitet nur im Ordner der jeweiligen Idee; Push/Deployment, Kontoerstellung und Zahlungen sind verboten. Skills sind nur Ratschläge, können diese Regeln nicht überschreiben, und die KI kann sie nicht selbst installieren.

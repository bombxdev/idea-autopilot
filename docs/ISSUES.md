## ISSUE-026 · 2026-11-04 · แก้แล้ว — โปรแกรมค้างถาวร (Not Responding) เพราะล็อกตัวเดียวกันถูกขอซ้ำในนิพจน์เดียว
- **อาการ:** ใช้งานไปแล้วหน้าต่างค้าง Windows ขึ้น “Not Responding” ไม่กลับมาเอง ต้องปิดแล้วเปิดใหม่ (เกิดตอนลองเพิ่มไอเดียด้วย Codex แบบอัตโนมัติ)
- **สาเหตุ (ตรวจจากโปรเซสที่ค้างจริง):** CPU 0%, เธรดหลักรอล็อกอยู่ และมี tokio worker อีก 2 ตัวรอล็อกเดียวกัน ไม่มีเธรดไหนทำงานอยู่ = deadlock. ค้นโค้ดเจอ 2 จุดที่เขียน `st.rt.lock().a() || st.rt.lock().b()` (และ `&&`): ตัวแปรชั่วคราวของล็อกแรกยังไม่ถูกปล่อยตอนขอล็อกที่สอง ล็อก `parking_lot` ขอซ้ำเธรดเดียวกันไม่ได้ จึงรอตัวเองตลอดไป และเพราะ `rt` ถูกใช้ทุกที่ ทั้งโปรแกรมค้างตาม: (1) `scheduler.rs` ตอนแก้ข้อความไอเดีย (`edit_idea`, ตัวแปร `busy`) ทำงานบนเธรดหลัก (2) `update.rs` ตอนตัวเช็กอัปเดตเบื้องหลังดูว่าบอทว่างไหม (`idle`) จุดที่ 2 ทำงานเองโดยไม่ต้องมีใครกดอะไร
- **วิธีแก้:** ขอล็อกครั้งเดียวแล้วถามทั้งสองคำถามจากตัวล็อกนั้น เพิ่มเทสต์ `state::lock_rules` ที่สแกนซอร์สทุกไฟล์ ถ้ามีบรรทัดที่ขอล็อก `rt`/`db` เดียวกันสองครั้งรวมกับ `&&`/`||` เทสต์จะล้ม
- **ตัวอื่นเป็นด้วยไหม:** สแกนด้วยสคริปต์ทั้งโปรเจกต์ (ล็อกซ้อนกันข้ามฟังก์ชัน, ล็อกคนละชนิดสลับลำดับ, guard ค้างใน `match`/`if let`, guard ข้าม `await` ด้วย clippy) ไม่พบอีก แต่การสแกนเป็นแบบประมาณ ไม่ใช่การพิสูจน์
- **ไฟล์:** `scheduler.rs`, `update.rs`, `state.rs` (เทสต์)
- **หมายเหตุ:** ยังไม่ได้ทำซ้ำอาการค้างโดยตรง ยืนยันจากหลักฐานในโปรเซสที่ค้างและตรรกะของโค้ด ถ้ายังค้างอีกหลังเวอร์ชันนี้ แจ้งได้ทันที (ตอนค้างอย่าเพิ่งปิด จะได้ตรวจซ้ำ)

## ISSUE-025 · 2026-11-04 · แก้แล้ว (ป้ายโมเดลฟรีทำได้เฉพาะที่ชื่อบอกเอง) — ช่องเลือกโมเดลเป็นช่องค้นหาเดียวกันทุกที่ + ติ๊กแสดงเฉพาะโมเดลฟรี
- **อาการ:** ในตั้งค่าบัญชี มี dropdown โมเดลแล้วยังมีช่องพิมพ์ชื่ออีกช่องอยู่ข้างๆ ทั้งที่เลือกจากรายการแล้ว ทำให้งง และ dropdown ค้นหาไม่ได้
- **วิธีแก้:** ทำ `ModelPicker.svelte` ช่องเดียวที่พิมพ์ค้นหาได้ทันที (กรองตามที่พิมพ์ ลูกศร/Enter/Esc ใช้ได้) พิมพ์ชื่อที่ไม่มีในรายการได้ด้วยตัวเลือก “ใช้ชื่อ …” และมีติ๊ก “แสดงเฉพาะโมเดลฟรี” เมื่อรายการมีโมเดลฟรีอย่างน้อยหนึ่งตัว ใช้เหมือนกันที่: โมเดลของบัญชี (ตั้งค่า), ฟอร์มเพิ่มบัญชี, AI ของไอเดีย และ AI ของแชต ฝั่งโปรแกรมใส่ `free` ให้โมเดลที่ชื่อบอกว่าฟรี (`:free` ของ OpenRouter, `-free` ของ OpenCode)
- **ไฟล์:** `ModelPicker.svelte` (ใหม่), `Accounts.svelte`, `IdeaAi.svelte`, `catalog.rs` (`is_free_model`), `commands.rs` (`account_models`)
- **หมายเหตุ:** ป้ายฟรีดูจากชื่อโมเดลเท่านั้น ค่ายที่มี “โควต้าฟรี” ของโมเดลปกติ (เช่น Gemini, Mistral) ไม่ถูกติดป้าย เพราะเงื่อนไขเปลี่ยนบ่อยและโปรแกรมตรวจเองไม่ได้ ยังไม่ได้ลองกับรายชื่อจริงของ OpenRouter

## ISSUE-024 · 2026-11-04 · แก้แล้ว (ส่วนเลือกบัญชี/โมเดลของแชตยังไม่ได้ทดสอบกับ Claude จริง) — ไฟล์แนบจากแชต, กล่องยืนยันของแอปเอง, เลือก AI/โมเดลในช่องแชต
- **ไฟล์ที่ส่งไปกับแชตค้างในรายการไฟล์แนบของไอเดีย:** ไฟล์ที่แนบมากับข้อความในช่อง “สั่ง AI แก้ / ทำต่อ” ถูกย้ายไป `attachments/sent/` ทันทีหลังส่ง (AI ยังเปิดอ่านได้ที่ path นั้น ซึ่งข้อความที่ส่งบอกไว้) จึงไม่โผล่ในรายการไฟล์แนบอีก ส่วนไฟล์ที่แนบกับปุ่มสั่งสั้นๆ (ไปต่อ/ขุดลึก…) ยังอยู่ในรายการ เพราะบอทอ่านทีหลังตอนทำขั้นถัดไป
- **popup แบบเบราว์เซอร์:** ทุกที่ที่เคยใช้ `confirm()` (ลบไฟล์แนบ, ลบ key, ลบ/ยกเลิกบัญชี, ลบสกิล, อัปเดต, ย้ายเครื่องหลัก, ติดตั้ง CLI) เปลี่ยนเป็นกล่องของแอปเอง (`ConfirmHost.svelte` + `lib/dialog.svelte.js`) มีหัวข้อ ข้อความ ปุ่มสีแดงเมื่อเป็นการลบ กล่องแสดงคำสั่ง กด Esc หรือคลิกนอกกล่องเพื่อยกเลิก
- **ช่องแชตในหน้าแก้ไขไอเดีย:** เอา dropdown ค่ายเดิมออก ใช้ตัวเลือก “🤖 AI สำหรับแชตนี้” แบบเดียวกับหน้าเพิ่มไอเดีย (บัญชี → โมเดล → effort) ซึ่งหุบไว้และเป็นอัตโนมัติ อัตโนมัติ = ตามที่ตั้งไว้ให้ไอเดียนี้ ไม่มีก็ใช้ค่าเริ่มต้นของ AI (ไม่สุ่ม) session ใหม่เปิดด้วย `--model`/`--effort` และ env ของบัญชีที่เลือก ถ้า session เปิดอยู่แล้วจะสลับโมเดลด้วย `/model` แต่เปลี่ยนบัญชีไม่ได้ต้องปิด session ก่อน (บอกในข้อความ) บัญชีค่ายอื่นยังส่งผ่าน terminal/Orca เหมือนเดิม
- **ไฟล์:** `attach.rs` (`move_to_sent`), `remote.rs` (`ChatAi`, `start_with`, `ask_with`), `commands.rs`, `agents.rs`, `IdeaAi.svelte`, `AskAI.svelte`, `ConfirmHost.svelte`, `dialog.svelte.js`
- **หมายเหตุ:** effort ของ session ที่เปิดอยู่แล้วเปลี่ยนไม่ได้ (ใช้ตอนเปิดเท่านั้น) และการสลับ `/model` กลางทางยังไม่ได้ลองกับ Claude Code จริง

## ISSUE-023 · 2026-11-04 · แก้แล้ว (ยังไม่ได้ลองติดตั้งจริงจนจบ) — ปุ่ม “⬇ ติดตั้ง CLI” ที่บัญชีที่ยังไม่ได้ติดตั้งโปรแกรม
- **อาการ:** บัญชีที่ขึ้น “ยังไม่ได้ติดตั้ง CLI” ทำงานไม่ได้ และต้องไปรันคำสั่งติดตั้งเองนอกโปรแกรม
- **วิธีแก้:** ใส่ปุ่ม “⬇ ติดตั้ง CLI” ข้างชิปนั้น (และในฟอร์มเพิ่มบัญชีเมื่อค่ายที่เลือกยังไม่ได้ติดตั้ง) กดแล้วโปรแกรมแสดงคำสั่งจริงให้ยืนยันก่อน (กด OK = ยินยอม) แล้วรันเฉพาะคำสั่งที่ผู้ให้บริการระบุ: `npm install -g …` (Claude Code, Codex, Gemini CLI, OpenCode) หรือ `uv tool install mistral-vibe` แบบไม่เปิดหน้าต่าง แสดงผลสดในหน้าบัญชี ถ้าล้มเพราะเครือข่าย/ใบรับรองจะลองซ้ำให้ใช้ใบรับรองของ Windows (`--use-system-ca`) และถ้าผู้ใช้กรอก registry สำรองไว้ (ไม่บังคับ) จะลองผ่านอันนั้นเป็นครั้งสุดท้าย ติดตั้งเสร็จจะล้างแคชการค้นหา AI แล้วโหลดรายการใหม่ ถ้าไม่มี Node.js/uv จะบอกคำสั่ง winget ให้ (ไม่ติดตั้งให้เอง) ทำได้ทีละตัว หมดเวลา 10 นาที
- **ไฟล์:** `cli_install.rs` (ใหม่), `providers.rs` (`forget_found`), `lib.rs`, `Accounts.svelte`, `api.js`, `mock.js`, `i18n/en.json`
- **หมายเหตุ:** ทดสอบหน่วย (คำสั่งตรงกับเอกสาร, registry ต้องเป็น https, ตรวจข้อผิดพลาดเครือข่าย) และ build ผ่าน แต่ยังไม่ได้กดติดตั้งจริงบนเครื่องที่ยังไม่มี CLI

## ISSUE-022 · 2026-11-04 · แก้แล้ว — แผนโควต้าแยก/รวมตามบัญชี, เลือก AI/โมเดล/effort ต่อไอเดีย, ใช้ /สกิล ตอนจดไอเดีย
- **แผนการใช้โควต้ายังเป็นของตัวหลักตัวเดียว:** เดิมส่วนบนของหน้าโควต้า (วงแหวนของสัปดาห์ + การ์ดสถานะ “บอททำงานได้/รออยู่”) อ่านเฉพาะการตัดสินใจของบัญชีที่บอทใช้อยู่ (Claude) และการเลือกแสดง/แยก/รวมของรอบก่อนทำกับกราฟประวัติเท่านั้น ตอนนี้เก็บการตัดสินใจ (governor) ของทุกบัญชีที่เปิดอยู่ แล้วหน้าโควต้ามีตัวเลือกเดียวที่ใช้ทั้งแผนและกราฟ: ติ๊กเลือกบัญชีที่จะแสดง (หรือกด “เฉพาะ”) และ “แยกกราฟ” = วงแหวนและการ์ดสถานะแยกของแต่ละบัญชี / “รวมกัน” = การ์ดเดียวที่เฉลี่ยบัญชีที่เลือก พร้อมสถานะรายบัญชีด้านล่าง บัญชีของบอท (ไม่แบ่งโควต้ากับคุณ) แสดง “ไม่ต้องกัน” และไม่มีส่วน “คุณใช้” ปุ่มพัก/Turbo เป็นของทั้งโปรแกรม
- **เลือก AI ต่อไอเดีย:** ตอนจดไอเดียใหม่ (ช่องจดด้านบน) และตอนดู/แก้ไอเดีย (หน้าไอเดีย) มีแถว “🤖 AI สำหรับไอเดียนี้” เลือกค่าย/บัญชี (เฉพาะที่เปิดอยู่) โมเดลและ effort (auto หรือเลือกจากสิ่งที่บัญชีนั้นใช้ได้ ตามรายชื่อที่อ่านจากบัญชี) บอททำไอเดียนั้นด้วยบัญชีที่ปักไว้ เมื่อโควต้าของบัญชีนั้นอนุญาต (ไม่ต้องรอบัญชีหลัก) และบังคับโมเดล/effort ตามที่เลือก (ชนะการตั้งค่ารายขั้นและของบัญชี) การ์ดไอเดียแสดงชิป 🤖 ของที่เลือก ไอเดียที่ไม่ได้ตั้ง ใช้ระบบอัตโนมัติเหมือนเดิม
- **ช่องจดไอเดียรับ `/สกิล`:** พิมพ์ `/` ขึ้นรายการสกิลแบบเดียวกับช่องคุยกับ AI (กรองตามตัวอักษรที่ขึ้นต้น ↑ ↓ Enter/Tab Esc) แล้วต่อด้วยสิ่งที่อยากทำ เช่น `/web-research ตลาดกาแฟ` จะจดไอเดีย “ตลาดกาแฟ” และปักสกิลนั้นกับไอเดีย (เสนอให้ AI ทุกรอบเป็นอันดับแรก + คำสั่งให้ใช้สกิลนั้น) ใช้ได้ทุกช่องทางที่จดไอเดีย (Telegram, `ia add`) เพราะทำที่ฝั่งหลังบ้าน สกิลที่ปิดอยู่หรือไม่ผ่านการตรวจถูกปฏิเสธพร้อมเหตุผล ข้อจำกัด: ช่องจดด่วน (Ctrl+Alt+Space) ยังไม่มีเมนูรายชื่อสกิลและตัวเลือก AI (พิมพ์ `/ชื่อสกิล …` เองได้ ทำงานเหมือนกัน)
- **ไฟล์:** `idea_ai.rs` (ใหม่), `scheduler.rs` (`next_pinned_idea`, `forced_model/forced_effort`, สกิลที่ปัก), `skills.rs` (`slash_skill`, `pinned_offers`), `commands.rs` (`add_idea`, `idea_ai_set`), `IdeaAi.svelte`, `PlanCard.svelte`, `QuotaPick.svelte` (ใหม่), `quotaview.svelte.js`, `Quota.svelte`, `AccountCharts.svelte`, `QuickAdd.svelte`, `IdeaDrawer.svelte`, `IdeaCard.svelte`, `SkillMenu.svelte`

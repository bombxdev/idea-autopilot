> अपना आइडिया एक पंक्ति में लिख दीजिए; आपका चुना हुआ AI एजेंट आपकी गैरहाज़िरी में उसे खोजेगा, परखेगा या पहला प्रोटोटाइप बना देगा — उस कोटा से जो वैसे बेकार जाता, और आपके काम के हिस्से को कभी नहीं छूता।

## मुख्य सुविधाएँ

- **एक पंक्ति में आइडिया**: AI रिसर्च करता है, परखता है और प्रोटोटाइप बनाता है।
- **कोई भी AI**: Claude Code, Codex CLI, Gemini CLI, OpenCode, Mistral Vibe या आपकी अपनी कमांड; कई अकाउंट।
- **बचा हुआ कोटा काम में**: पहले आपके काम का हिस्सा सुरक्षित रखा जाता है, कार्य-समय (कैलेंडर) से बचा जाता है, केवल बाकी इस्तेमाल होता है।
- **कठिनाई के अनुसार मॉडल और effort अपने-आप**: तय नियम, चुनने में टोकन खर्च नहीं।
- **डेटा सिर्फ़ आपके PC पर**: न टेलीमेट्री, न सर्वर; हर आइडिया का एक git रिपॉज़िटरी।
- **स्किल लाइब्रेरी**: एक जैसी “रेसिपी” बारी-बारी आज़माई जाती हैं और नतीजे गिने जाते हैं; मुफ़्त स्किल शॉप इंस्टॉल से पहले सुरक्षा जाँचती है।
- **फ़ोन**: अपने Telegram बॉट से सूचनाएँ और आइडिया।
- **16 भाषाओं में इंटरफ़ेस** (बाकी भाषाएँ आपके अपने AI से अनूदित)।

## इंस्टॉल (सबसे आसान से शुरू)

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

Windows 10/11, git और कम से कम एक लॉग-इन AI एजेंट चाहिए। Windows SmartScreen चेतावनी दे सकता है (अभी साइन नहीं): More info → Run anyway।

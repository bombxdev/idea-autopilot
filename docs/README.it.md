> Annota un’idea in una riga; l’agente IA che scegli la ricerca, la valuta o ne costruisce una prima versione mentre sei via — con la quota che altrimenti andrebbe sprecata, senza mai toccare la parte che ti serve per lavorare.

## Funzioni principali

- **Un’idea, una riga**: l’IA ricerca, valuta e crea prototipi.
- **Qualsiasi IA**: Claude Code, Codex CLI, Gemini CLI, OpenCode, Mistral Vibe o un tuo comando; più account.
- **Sfrutta la quota avanzata**: prima riserva ciò che ti serve per lavorare, evita l’orario di lavoro (calendario) e usa solo il resto.
- **Modello e impegno scelti in automatico in base alla difficoltà**: regole fisse, nessun token speso per decidere.
- **I dati restano sul tuo PC**: niente telemetria né server, un repository git per idea.
- **Libreria di skill**: più “ricette” dello stesso tipo vengono provate a turno e misurate; lo shop gratuito controlla la sicurezza prima dell’installazione.
- **Smartphone**: notifiche e idee dal tuo bot Telegram.
- **Interfaccia in 16 lingue** (le altre si traducono con la tua IA).

## Installazione (dalla più semplice)

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

Servono Windows 10/11, git e almeno un agente IA con accesso effettuato. Windows SmartScreen può avvisare (non ancora firmato): Ulteriori informazioni → Esegui comunque.

[Releases](https://github.com/bombxdev/idea-autopilot/releases) — Setup.exe / portable zip

## Sicurezza

Il bot lavora solo nella cartella di ciascuna idea; push/deploy, creazione di account e pagamenti sono vietati. Le skill sono solo consigli, non possono scavalcare queste regole e l’IA non può installarle da sola.

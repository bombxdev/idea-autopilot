> Запишите идею одной строкой — выбранный вами ИИ-агент исследует её, оценит или сделает первый прототип, пока вас нет. Используется квота, которая иначе пропала бы, а то, что нужно для вашей работы, не трогается.

## Основные возможности

- **Идея в одну строку**: ИИ исследует, оценивает и делает прототип.
- **Любой ИИ**: Claude Code, Codex CLI, Gemini CLI, OpenCode, Mistral Vibe или ваша команда; несколько аккаунтов.
- **Использует остаток квоты**: сначала резервируется доля для вашей работы, рабочее время (календарь) обходится, тратится только остаток.
- **Модель и усилие выбираются автоматически по сложности**: фиксированные правила, токены на выбор не тратятся.
- **Данные только на вашем ПК**: без телеметрии и сервера, один git-репозиторий на идею.
- **Библиотека навыков**: несколько «рецептов» одного типа пробуются по очереди, результат считается; бесплатный магазин навыков проверяет безопасность перед установкой.
- **Телефон**: уведомления и ввод идей через ваш собственный Telegram-бот.
- **Интерфейс на 16 языках** (остальные переводятся вашим ИИ).

## Установка (от самого простого)

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

Нужны Windows 10/11, git и хотя бы один ИИ-агент с выполненным входом. Windows SmartScreen может предупредить (подписи пока нет): Подробнее → Выполнить в любом случае.

[Releases](https://github.com/bombxdev/idea-autopilot/releases) — Setup.exe / portable zip

## Безопасность

Бот работает только в папке каждой идеи; push/деплой, создание аккаунтов и платежи запрещены. Навыки — лишь советы, они не отменяют эти правила, а ИИ не может устанавливать их сам.

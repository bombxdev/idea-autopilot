> Catat ide dalam satu baris; agen AI pilihan Anda meriset, menilai, atau membuat prototipe pertama saat Anda pergi — memakai kuota yang biasanya terbuang, dan tidak pernah menyentuh bagian yang Anda butuhkan untuk bekerja.

## Fitur utama

- **Catat ide satu baris**: AI meriset, menilai, dan membuat prototipe.
- **AI apa pun**: Claude Code, Codex CLI, Gemini CLI, OpenCode, Mistral Vibe, atau perintah Anda sendiri; mendukung banyak akun.
- **Memakai kuota sisa**: kuota untuk pekerjaan Anda diamankan dulu, jam kerja (kalender) dihindari, sisanya baru dipakai.
- **Model dan tingkat usaha dipilih otomatis sesuai kesulitan**: aturan tetap, tanpa menghabiskan token untuk memilih.
- **Data hanya di komputer Anda**: tanpa telemetri dan server, satu repositori git per ide.
- **Perpustakaan skill**: “resep” sejenis dicoba bergantian dan hasilnya dicatat; toko skill gratis memindai keamanan sebelum dipasang.
- **Ponsel**: notifikasi dan input ide lewat bot Telegram Anda sendiri.
- **Antarmuka 16 bahasa** (bahasa lain diterjemahkan dengan AI Anda).

## Pemasangan (dari yang termudah)

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

Perlu Windows 10/11, git, dan minimal satu agen AI yang sudah login. Windows SmartScreen mungkin memberi peringatan (belum ditandatangani): More info → Run anyway.

[Releases](https://github.com/bombxdev/idea-autopilot/releases) — Setup.exe / portable zip

## Keamanan

Bot hanya bekerja di folder tiap ide; dilarang push/deploy, membuat akun, dan membayar. Skill hanyalah saran, tidak bisa menimpa aturan ini, dan AI tidak dapat memasang skill sendiri.

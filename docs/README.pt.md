> Anote uma ideia numa linha; o agente de IA que você escolher pesquisa, avalia ou constrói uma primeira versão enquanto você está fora — usando a cota que seria desperdiçada, sem nunca tocar na parte de que você precisa para trabalhar.

## Principais recursos

- **Uma ideia, uma linha**: a IA pesquisa, avalia e faz protótipos.
- **Qualquer IA**: Claude Code, Codex CLI, Gemini CLI, OpenCode, Mistral Vibe ou seu próprio comando; várias contas.
- **Aproveita a cota que sobra**: reserva primeiro o que você precisa para trabalhar, evita seu horário de trabalho (calendário) e usa só o resto.
- **Modelo e esforço automáticos conforme a dificuldade**: regras fixas, sem gastar tokens para decidir.
- **Seus dados ficam no seu PC**: sem telemetria nem servidor, um repositório git por ideia.
- **Biblioteca de skills**: várias “receitas” do mesmo tipo são testadas em rodízio e medidas; a loja gratuita verifica a segurança antes de instalar.
- **Celular**: avisos e ideias pelo seu próprio bot do Telegram.
- **Interface em 16 idiomas** (os demais são traduzidos com a sua própria IA).

## Instalação (do mais fácil ao menos fácil)

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

Requer Windows 10/11, git e pelo menos um agente de IA conectado. O Windows SmartScreen pode avisar (ainda sem assinatura): Mais informações → Executar assim mesmo.

[Releases](https://github.com/bombxdev/idea-autopilot/releases) — Setup.exe / portable zip

## Segurança

O bot trabalha só na pasta de cada ideia; push/deploy, criação de contas e pagamentos são proibidos. Skills são apenas conselhos, não podem substituir essas regras, e a IA não consegue instalá-las sozinha.

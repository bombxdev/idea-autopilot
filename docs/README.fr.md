> Notez une idée en une ligne ; l’agent IA de votre choix la recherche, l’évalue ou en construit une première version pendant votre absence — avec le quota qui serait perdu, sans jamais toucher à la part dont vous avez besoin pour travailler.

## Fonctions principales

- **Une idée, une ligne** : l’IA recherche, juge et prototype.
- **Toute IA** : Claude Code, Codex CLI, Gemini CLI, OpenCode, Mistral Vibe ou votre propre commande ; plusieurs comptes.
- **Exploite le quota restant** : votre part de travail est réservée d’abord, vos heures de travail (calendrier) sont évitées, seul le reste est utilisé.
- **Modèle et effort choisis automatiquement selon la difficulté** : règles fixes, aucun jeton dépensé pour décider.
- **Vos données restent sur votre PC** : ni télémétrie ni serveur, un dépôt git par idée.
- **Bibliothèque de skills** : plusieurs « recettes » du même type sont essayées à tour de rôle et mesurées ; la boutique gratuite analyse la sécurité avant installation.
- **Mobile** : notifications et saisie d’idées via votre propre bot Telegram.
- **Interface en 16 langues** (les autres se traduisent avec votre propre IA).

## Installation (du plus simple au moins simple)

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

Nécessite Windows 10/11, git et au moins un agent IA connecté. Windows SmartScreen peut avertir (pas encore signé) : Informations complémentaires → Exécuter quand même.

[Releases](https://github.com/bombxdev/idea-autopilot/releases) — Setup.exe / portable zip

## Sécurité

Le bot travaille uniquement dans le dossier de chaque idée ; push/déploiement, création de comptes et paiements sont interdits. Les skills ne sont que des conseils, elles ne peuvent pas passer outre ces règles, et l’IA ne peut pas les installer seule.

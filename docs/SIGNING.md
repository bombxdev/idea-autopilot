# เซ็นชื่อตัวติดตั้ง Windows (ให้ไม่ขึ้นคำเตือน “ไม่รู้จักผู้เผยแพร่”)

ตอนนี้ `IdeaAutopilot-<ver>-Setup.exe` **ยังไม่ได้เซ็นชื่อ** Windows SmartScreen จึงขึ้น “Windows protected your PC” ผู้ใช้ต้องกด **More info → Run anyway** (ไม่ใช่ไวรัส แต่ Windows ยังไม่รู้จักผู้เผยแพร่)

การเซ็นชื่อต้องยืนยันตัวตนผู้เผยแพร่กับผู้ออกใบรับรอง ซึ่งต้องทำโดยเจ้าของโปรเจกต์เอง (บัตรประชาชน/องค์กร) ตัวสคริปต์เตรียมไว้แล้ว: ตั้งค่า `IA_SIGN_THUMBPRINT` แล้วรัน `scripts\package.ps1` จะเซ็นทั้งโปรแกรมและตัวติดตั้งให้

## ทางเลือก (ข้อมูลตรวจเมื่อ ต.ค. 2026 — ราคาและเงื่อนไขเปลี่ยนได้ ตรวจหน้าทางการก่อนสมัคร)

| ทาง | ค่าใช้จ่าย | ข้อดี | ข้อจำกัด |
|---|---|---|---|
| **Microsoft Store (MSIX)** | ลงทะเบียนนักพัฒนาบุคคลธรรมดาฟรี (ประกาศ ก.ย. 2025 ทั่วโลก) | Microsoft เซ็นชื่อให้ ติดตั้งผ่าน Store ไม่ขึ้นคำเตือน อัปเดตอัตโนมัติ | ต้องยืนยันตัวตน (บัญชี Microsoft + บัตร + เซลฟี่) ผ่านการตรวจแอป และต้องแพ็กเป็น MSIX/ส่งตัวติดตั้งเข้า Store (ต้องปรับ build) |
| **SignPath Foundation** | ฟรี สำหรับโปรเจกต์โอเพนซอร์ส | ใบรับรองจริง ใช้กับ CI | ต้องเป็นโอเพนซอร์ส (license ที่ OSI รับรอง) ใน repo สาธารณะ ผู้เผยแพร่ที่แสดงจะเป็น “SignPath Foundation” ต้องเปิดเผย source และผ่านการอนุมัติ |
| **Azure Artifact Signing** (เดิม Trusted Signing) | ราว 9.99 ดอลลาร์/เดือน | เซ็นผ่าน CI ง่าย ชื่อผู้เผยแพร่เป็นของเรา | บุคคลธรรมดาจำกัดบางประเทศ (รายงานล่าสุดคือสหรัฐฯ/แคนาดา ฯลฯ) ประเทศไทยอาจสมัครไม่ได้ ต้องเช็กในพอร์ทัล |
| ใบรับรอง OV/EV จากผู้ออกใบรับรองทั่วไป | หลักร้อยถึงพันดอลลาร์/ปี | ใช้ได้ทุกที่ | มีค่าใช้จ่าย (ขัดกับหลัก “ฟรีก่อน”) OV ยังต้องสะสมชื่อเสียง SmartScreen อยู่พักหนึ่ง EV ผ่านทันที |

หมายเหตุ: แม้เซ็นชื่อแล้ว ใบรับรองแบบ OV อาจยังมีคำเตือนช่วงแรกจนกว่าจะมีคนติดตั้งมากพอ ส่วน Store ไม่มีปัญหานี้

## ใช้ใบรับรองที่มีอยู่แล้ว
1. ติดตั้งใบรับรองลง Windows (Personal store) แล้วดู thumbprint
2. `$env:IA_SIGN_THUMBPRINT = "<thumbprint>"` แล้วรัน `powershell -ExecutionPolicy Bypass -File scripts\package.ps1`
3. สคริปต์จบด้วยบรรทัด `signature: Valid`
สำหรับ SignPath/Azure ที่เซ็นผ่านบริการ ให้ตั้ง `signCommand` ใน `tauri.conf.json` ตามเอกสารของบริการนั้น

## ระหว่างที่ยังไม่เซ็นชื่อ
- บอกผู้รับว่าจะเจอหน้าเตือน SmartScreen และให้กด More info → Run anyway
- ส่งไฟล์ที่เจอ false positive ให้ Microsoft ตรวจ: https://www.microsoft.com/wdsi/filesubmission

> Anota una idea en una línea; el agente de IA que elijas la investiga, la evalúa o construye una primera versión mientras estás fuera — con la cuota que de otro modo se perdería, sin tocar nunca la parte que necesitas para trabajar.

## Funciones principales

- **Una idea, una línea**: la IA investiga, juzga y hace prototipos.
- **Cualquier IA**: Claude Code, Codex CLI, Gemini CLI, OpenCode, Mistral Vibe o tu propio comando; varias cuentas.
- **Aprovecha la cuota sobrante**: reserva primero lo que necesitas para trabajar, evita tu horario laboral (calendario) y usa solo el resto.
- **Modelo y esfuerzo automáticos según la dificultad**: reglas fijas, sin gastar tokens en decidir.
- **Tus datos se quedan en tu PC**: sin telemetría ni servidor, un repositorio git por idea.
- **Biblioteca de skills**: varias “recetas” del mismo tipo se prueban por turnos y se mide el resultado; la tienda gratuita analiza la seguridad antes de instalar.
- **Móvil**: avisos e ideas desde tu propio bot de Telegram.
- **Interfaz en 16 idiomas** (los demás se traducen con tu propia IA).

## Instalación (de lo más fácil a lo menos)

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

Requiere Windows 10/11, git y al menos un agente de IA con sesión iniciada. Windows SmartScreen puede avisar (aún sin firmar): Más información → Ejecutar de todos modos.

[Releases](https://github.com/bombxdev/idea-autopilot/releases) — Setup.exe / portable zip

## Seguridad

El bot solo trabaja dentro de la carpeta de cada idea; no puede hacer push/desplegar, crear cuentas ni pagar. Las skills son consejos y no anulan estas reglas; la IA no puede instalarlas por su cuenta.

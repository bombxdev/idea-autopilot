## ข้อความโพสต์ (ก๊อปไปวางได้เลย)

🌙 ตื่นมาเจอคำตอบ — จดไอเดียไว้บรรทัดเดียว ให้ AI ทำให้ตอนคุณไม่อยู่

มีไอเดียเยอะแต่เวลาน้อยใช่ไหม? Idea Autopilot คือโปรแกรมเล็กๆ บน Windows ที่เอาโควต้า AI ที่คุณจ่ายไปแล้วแต่ใช้ไม่หมด ไปค้นคว้า ตัดสิน หรือทำต้นแบบแรกให้ โดยกันส่วนที่คุณต้องใช้ทำงานไว้ก่อนเสมอ

✅ ฟีเจอร์เด่น
1. จดไอเดียบรรทัดเดียว AI ไปค้นคว้า ตัดสินใจ หรือสร้างต้นแบบให้
2. ใช้ AI ได้ทุกค่าย: Claude Code, Codex, Gemini, OpenCode, Mistral Vibe หรือคำสั่งของคุณเอง และมีได้หลายบัญชี
3. ใช้โควต้าที่เหลือทิ้งให้คุ้ม กันส่วนงานของคุณไว้ก่อน และหลบเวลางานตามปฏิทิน
4. เลือกโมเดลและระดับความพยายามตามความยากให้เอง ด้วยกฎตายตัว ไม่เสียโควต้าไปคิด
5. ข้อมูลอยู่ในเครื่องคุณเท่านั้น ไม่มี telemetry ไม่มีเซิร์ฟเวอร์ ไอเดียละ 1 git repo
6. ระบบสกิล: เก็บ “สูตร” หลายแบบของงานเดียวกัน ลองสลับและวัดผลให้ พร้อมร้านสกิลฟรีที่สแกนความปลอดภัยก่อนติดตั้งทุกครั้ง
7. ถามคำถามสั้นๆ ให้แตะเลือกตอบ และมีหน้า “เช้านี้” สรุปว่าเมื่อคืนได้อะไร
8. แจ้งเตือนและจดไอเดียจากมือถือผ่าน Telegram บอทของคุณเอง
9. หน้าจอ 16 ภาษา
10. ปลอดภัย: ทำงานเฉพาะในโฟลเดอร์ของแต่ละไอเดีย ห้าม push/จ่ายเงิน/สมัครบัญชี และฟรีตลอด (โอเพนซอร์ส GPL-3.0)

## ทำฟอร์ม “ลงชื่อ” ฟรีใน 2 นาที

1. เปิด Google Forms (ฟรี) สร้างฟอร์มใหม่ ชื่อ “ลงชื่อทดลอง Idea Autopilot”
2. คำถามที่ควรมี: ชื่อ, ช่องทางที่ให้ส่งลิงก์ (ชื่อ Facebook หรืออีเมล), ใช้ AI ตัวไหนอยู่ (ติ๊กเลือก), มี git ในเครื่องแล้วหรือยัง
3. ใส่ข้อความบอกชัดว่า “ข้อมูลนี้ใช้ส่งลิงก์โปรแกรมเท่านั้น”
4. เปิดแท็บ ตอบกลับ → ลิงก์ไป Google Sheets เพื่อดูรายชื่อ แล้วทักส่งลิงก์ทาง Inbox ทีละคน
5. เอาลิงก์ฟอร์มมาแทน `[ใส่ลิงก์ฟอร์มลงชื่อ]` ในโพสต์

ทางเลือกที่ไม่ต้องทำฟอร์ม: ให้คนคอมเมนต์ว่า “สนใจ” ใต้โพสต์ แล้วทักไปทาง Inbox เอง
(ลิงก์โปรแกรมเป็นสาธารณะอยู่แล้ว การลงชื่อเป็นแค่ช่องทางทักทายและเก็บฟีดแบ็ก)

ข้อควรระวัง: โปรแกรมยังไม่ได้เซ็นชื่อผู้เผยแพร่ Windows อาจขึ้นหน้าเตือน SmartScreen ให้บอกคนลองว่ากด More info → Run anyway และบอกด้วยว่าต้องมี git กับ AI ที่ล็อกอินแล้วอย่างน้อย 1 ตัว

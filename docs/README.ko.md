> 아이디어를 한 줄로 적어 두면, 선택한 AI 에이전트가 자리를 비운 사이 조사하고, 판단하고, 첫 시제품까지 만들어 줍니다. 버려질 한도만 사용하며 업무에 필요한 몫은 건드리지 않습니다.

## 주요 기능

- **한 줄로 아이디어 기록**: AI가 조사·판단·프로토타입을 진행합니다.
- **어떤 AI든**: Claude Code, Codex CLI, Gemini CLI, OpenCode, Mistral Vibe 또는 직접 만든 명령. 여러 계정 지원.
- **남는 한도 활용**: 업무용 한도를 먼저 확보하고, 근무 시간(캘린더)을 피해 나머지만 사용합니다.
- **난이도에 맞춰 모델·강도 자동 선택**: 고정 규칙이라 고르는 데 토큰을 쓰지 않습니다.
- **데이터는 내 PC에만**: 텔레메트리도 서버도 없고, 아이디어마다 git 저장소 하나.
- **스킬 라이브러리**: 같은 용도의 “레시피”를 번갈아 시도하고 성과를 기록. 무료 스킬 상점은 설치 전에 안전성을 검사합니다.
- **휴대폰**: 내 Telegram 봇으로 알림 수신과 아이디어 입력.
- **16개 언어 화면**(나머지는 내 AI로 번역).

## 설치 (쉬운 순서)

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

Windows 10/11, git, 로그인된 AI 에이전트 1개 이상이 필요합니다. SmartScreen 경고가 뜰 수 있습니다(서명 전): 추가 정보 → 실행.

[Releases](https://github.com/bombxdev/idea-autopilot/releases) — Setup.exe / portable zip

## 안전

봇은 각 아이디어 폴더 안에서만 동작하며 push·배포·계정 생성·결제는 금지입니다. 스킬은 조언일 뿐 이 규칙을 덮어쓸 수 없고, AI가 스스로 스킬을 설치할 수도 없습니다.

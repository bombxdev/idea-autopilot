## الميزات الرئيسية

</div>

<div dir="rtl">

- **فكرة في سطر واحد**: يبحث الذكاء الاصطناعي ويقيّم وينشئ نموذجًا أوليًا.
- **أي وكيل ذكاء اصطناعي**: Claude Code وCodex CLI وGemini CLI وOpenCode وMistral Vibe أو أمرك الخاص، مع دعم عدة حسابات.
- **يستفيد من الحصة المتبقية**: تُحجز حصة عملك أولًا، وتُتجنَّب ساعات العمل (التقويم)، ولا يُستخدم إلا الباقي.
- **اختيار تلقائي للنموذج والجهد حسب الصعوبة**: قواعد ثابتة بلا إنفاق رموز على الاختيار.
- **بياناتك على جهازك فقط**: بلا تتبّع ولا خادم، ومستودع git لكل فكرة.
- **مكتبة مهارات**: تُجرَّب «وصفات» متشابهة بالتناوب ويُقاس أداؤها؛ ومتجر المهارات المجاني يفحص الأمان قبل التثبيت.
- **الهاتف**: إشعارات وإدخال أفكار عبر بوت Telegram الخاص بك.
- **واجهة بـ16 لغة** (وتُترجم البقية بذكائك الاصطناعي الخاص).

</div>

## التثبيت (من الأسهل)

</div>

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

<div dir="rtl">

يتطلب Windows 10/11 وgit ووكيل ذكاء اصطناعي واحدًا على الأقل مسجّلًا الدخول. قد يحذّر Windows SmartScreen (غير موقّع بعد): More info ← Run anyway.

</div>
